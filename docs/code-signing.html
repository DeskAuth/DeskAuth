Code signing

The DeskAuth downloads are not code signed. A code signing certificate costs money every year, and DeskAuth is a free project. This is why Windows SmartScreen may warn you the first time you run a downloaded file, and why Digital Signatures doesn't appear in the file's properties.

How to check a download

Without a signature, you can still check that a file is the one we published:

  1. Download it only from the GitHub releases page or the download page, which links there.
  2. In PowerShell, run Get-FileHash DeskAuth-version-x64.exe, using the name of the file you downloaded.
  3. Compare the result with that file's line in SHA256SUMS.txt, attached to the same release. Upper or lower case doesn't matter. If they are different, don't run the file.

How the downloads are built

Each download is built by GitHub Actions, on GitHub's own servers, from the public source code in the DeskAuth repository at the release's tag, using the release workflow. You can read the code, see the build for each release on the Actions page, or build DeskAuth yourself.

The Microsoft Store version

The Microsoft Store version is signed by Microsoft, which signs the apps it distributes through the Store, so SmartScreen doesn't warn about it. See the Microsoft Store version in the help.

Reporting a problem

If you find a DeskAuth file that doesn't match its checksum, or you have found a security problem, email security@deskauth.com. See the security policy.
